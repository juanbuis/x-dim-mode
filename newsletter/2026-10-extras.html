Bring back old Twitter with Extras

Hey,

Thanks for using Dim Mode, and for signing up to hear about it. I only email when there's something worth telling you, and today there is.

Click the Dim Mode icon in your toolbar and you'll find Extras: seven toggles that bring back bits of old Twitter.

They're all off until you turn them on, so nothing changes unless you want it to:
• Classic bird logo. The bird, back where the X is.
• Classic font. Helvetica Neue, what Twitter used before Chirp.
• Classic favicon. The little blue bird in your tab again.
• “Tweet”, not “Post”. The old words, right down to the compose button.
• Start on Following. Opens on Following instead of For you.
• Classic image grid. Posts with several photos show them all in a grid again, not a carousel.
• Copy link first. Copy link back at the top of the share menu, where it used to be.

Turn on whatever you like the look of. Leave the rest alone.

A new name

X Dim Mode is now called Dim Mode for Twitter / X. Same extension, same settings, you don't need to do anything. And a version for Safari on the Mac is on its way.

If something looks off

X changes its design all the time, and now and then that breaks something here. Most recently it made Chat black again, which the latest update fixes. If you spot anything, use the “Report a problem” link in the popup. I read every one, and fixes usually go out within a few days.

Thanks for using it. It's nice knowing this many people still want their old Twitter back.
