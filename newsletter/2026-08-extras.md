# Newsletter — first send to the xdim.app list

Angle is **Extras discovery**, not the release: Chrome already auto-updated
everyone and they've seen the update screen, so a "what's new" email mostly
repeats itself. What they genuinely don't know is that six optional features sit
behind a row in the popup.

Voice: warm and conversational, "we" not "I", no marketing-speak. American
spelling, matching the extension's own copy.

---

## Subject line

**A (recommended):** Six small things hiding in X Dim Mode
**B (test against it):** You're probably using half of X Dim Mode

A is friendly and promises a list. B is curiosity-led and will likely win opens,
but it nudges toward growth-hack territory — if they're close, keep A.

**Preheader:** The bird logo, the old font, and an image grid that stopped cropping.

---

## Body

Hey,

Thanks for installing X Dim Mode, and for signing up to hear from us. We
promised a few emails a year and we meant it, so this is the first one.

Here's the thing we keep hearing: most people never find half of what's in
there.

Which is fair enough. You came for the dark blue background — that's the whole
reason it exists. But if you click the X Dim Mode icon in your toolbar, there's
a row called **Extras**, and behind it are six optional toggles. They're all off
by default, so nothing changes unless you decide you want it to:

- **Classic bird logo** — the bird, back where the X is
- **Classic font** — Helvetica Neue, what Twitter used before Chirp
- **Classic favicon** — the little blue bird in your tab again
- **"Tweet", not "Post"** — the old wording, right down to the compose button
- **Start on Following** — opens on Following instead of For You
- **Classic image grid** — the newest one, and our favorite

Turn on whatever you like the look of. Leave the rest alone.

**About that last one**

X quietly moved multi-image posts to a side-scrolling carousel, which shoves
half the pictures off the edge of the screen. The classic grid brings the old
layout back so you can see all of them at once. Small thing — but it's the kind
of small thing that bugs you every single day.

**A couple of other bits**

Turning Dim off now actually turns it off. It used to leave the page dimmed
until you reloaded, which was annoying, and is now fixed. X Dim Mode also landed
on Firefox, including Firefox for Android.

**If something looks off**

X redesigns things constantly, and every so often that breaks something here.
There's a "Report a problem" link right in the popup — we read all of them, and
fixes usually go out within a few days. Honestly the fastest way to get
something sorted.

Thanks for using it. It's nice knowing this many people still want their old
Twitter back.

— X Dim Mode
xdim.app

P.S. If you'd rather get updates in your timeline than your inbox, we're at
[@juanbuis](https://x.com/juanbuis).

## Notes for sending

**The call to action is a click, not a link.** "Open the popup, click Extras."
No URL opens that menu, so don't manufacture one — the whole email exists to
make that single click feel worth it.

**Segmentation, if you want it.** `signup_source` splits the list four ways:

| Source | Seen the 1.7.0 changelog? |
|---|---|
| `extension-update` | Yes — the update screen showed it |
| `extension-welcome` | No — installed at some other version |
| `extension-popup` | No |
| `website` | No, and some may not have installed at all |

Only `extension-update` has read the "what's new" part already. To be precise,
cut "A couple of other bits" for that segment; everything else still lands,
because the Extras pitch is new to all four.

`website` is the odd one — some subscribed without installing, so "click the
icon in your toolbar" doesn't apply. If that group is large it wants its own
send with an install link.

**Before sending:** delete the test subscribers (search `+xdm-`).

**On timing.** The list was built on "a few emails a year" and has never been
sent to. A first email arriving long after signup gets marked spam by people who
forgot subscribing, which damages deliverability for every later send. Sooner is
safer.
