# Newsletter — first send to the xdim.app list

Angle is **Extras as news**: the menu just landed, and that's the reason the
email exists at all. "You haven't found this yet" read as a scold and gave no
reason for the send; "this is new, here's what it does" gives both. An animated
hero at the top (hosted at https://xdim.app/extras-demo.gif, built from the
extension's real assets) shows a toggle flipping and the bird / Tweet / grid
appearing — excitement before a single line is read.

Voice: warm and conversational, "we" not "I", no marketing-speak. American
spelling, matching the extension's own copy.

---

## Subject line

**A (recommended):** New in X Dim Mode: Extras
**B (test against it):** Six new toggles for X Dim Mode

Both are newsy; A leads with the name, B with the count.

**Preheader:** Six new toggles: the bird, the old font, "Tweet" not "Post", and the classic image grid.

---

## Body

*(top of email: NEW badge, headline "Extras just landed in X Dim Mode", then
the animated toggle demo)*

Hey,

Thanks for installing X Dim Mode, and for signing up to hear from us. We
promised we'd only email when there's something genuinely new — and today
there is.

**X Dim Mode now comes with Extras: six optional toggles that bring back the
best parts of old Twitter.**

You came for the dark blue background — that's still the heart of it. But
click the X Dim Mode icon in your toolbar and you'll find the new Extras menu
right underneath. Everything in it is off by default, so nothing changes
unless you decide you want it to:

- **Classic bird logo** — the bird, back where the X is
- **Classic font** — Helvetica Neue, what Twitter used before Chirp
- **Classic favicon** — the little blue bird in your tab again
- **"Tweet", not "Post"** — the old wording, right down to the compose button
- **Start on Following** — opens on Following instead of For You
- **Classic image grid** — multi-image posts back in a grid, instead of a
  carousel that hides half of them

Turn on whatever you like the look of. Leave the rest alone.

**If something looks off**

X redesigns things constantly, and every so often that breaks something here.
There's a "Report a problem" link right in the popup — we read all of them, and
fixes usually go out within a few days. Honestly the fastest way to get
something sorted.

Thanks for using it. It's nice knowing this many people still want their old
Twitter back.

— X Dim Mode
xdim.app

P.S. If you'd rather get updates in your timeline than your inbox, we're at
[@juanbuis](https://x.com/juanbuis).

## Notes for sending

**The call to action is a click, not a link.** "Open the popup, click Extras."
No URL opens that menu, so don't manufacture one — the whole email exists to
make that single click feel worth it.

**Segmentation, if you want it.** `signup_source` splits the list four ways:

| Source | Seen the 1.7.0 changelog? |
|---|---|
| `extension-update` | Yes — the update screen showed it |
| `extension-welcome` | No — installed at some other version |
| `extension-popup` | No |
| `website` | No, and some may not have installed at all |

This mattered more when the email carried release notes. It no longer does —
the whole thing is now the Extras pitch, which is equally new to all four
sources. Send it to everyone.

`website` is the odd one — some subscribed without installing, so "click the
icon in your toolbar" doesn't apply. If that group is large it wants its own
send with an install link.

**Before sending:** delete the test subscribers (search `+xdm-`).

**On timing.** The list was built on "a few emails a year" and has never been
sent to. A first email arriving long after signup gets marked spam by people who
forgot subscribing, which damages deliverability for every later send. Sooner is
safer.
