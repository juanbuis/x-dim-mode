# Newsletter — "Six things hiding in X Dim Mode"

First send to the xdim.app list. Angle is **Extras discovery**, not the release:
Chrome already auto-updated everyone and they've seen the update screen, so a
"what's new" email mostly repeats itself. What they genuinely don't know is that
six optional features exist behind a row in the popup.

---

## Subject line

**A (recommended):** Six things hiding in X Dim Mode
**B (test against it):** You're using about a third of X Dim Mode

A is concrete and promises a list. B is curiosity-led and will likely win opens
but risks feeling like a growth-hack subject; if the open rates are close, keep A.

**Preheader:** The bird logo, the old font, and an image grid that stopped cropping.

---

## Body

You signed up for the occasional X Dim Mode email. Here's one.

**Most people install X Dim Mode for the dark blue background and never find the rest.**

Click the X Dim Mode icon in your toolbar and there's a row called **Extras**.
Six optional toggles, all off by default:

- **Classic bird logo** — the bird instead of the X
- **Classic font** — Helvetica Neue, what X used before Chirp
- **Classic favicon** — the Twitter bird back in your tab
- **"Tweet", not "Post"** — the old wording, compose button included
- **Start on Following** — open on Following instead of For You
- **Classic image grid** — brand new, and the best one

Turn on what you want, ignore the rest.

**About that image grid**

X moved multi-image posts to a side-scrolling carousel that pushes pictures
off-screen. The classic grid puts all of them back on one screen, the way it
used to work.

**Also in this update**

Turning Dim off now actually turns it off — the toggle used to leave the page
dimmed until you reloaded. And X Dim Mode now runs on Firefox too, including
Firefox for Android.

**If something looks broken**

X changes its layout constantly, and when it does, something here occasionally
breaks. There's a "Report a problem" link in the popup. Reports get read, and
fixes usually ship within a few days.

— X Dim Mode

## Notes for sending

**The call to action is behavioural, not a link.** "Open the popup, click Extras."
There is no URL that opens the Extras menu, so don't manufacture one — the whole
email is built to make that one click feel worth it.

**Segmentation, if you want it.** `signup_source` splits the list four ways:

| Source | Have they seen the 1.7.0 changelog? |
|---|---|
| `extension-update` | Yes — the update screen showed it |
| `extension-welcome` | No — they installed at some other version |
| `extension-popup` | No |
| `website` | No, and some may not even have installed it |

Only `extension-update` has already read the "what's new" part. If you want to
be precise, cut the "Also in this update" section for that segment — everything
else still lands, because the Extras pitch is new to all four.

The `website` segment is the odd one: some subscribed without installing. If
that group is large, it deserves its own send with an install link rather than
"click the icon in your toolbar".

**Before sending:** delete the test subscribers (search `+xdm-`).

**On timing.** The list was built on a promise of "a few emails a year" and has
never been sent to. A first email that arrives long after signup gets marked as
spam by people who forgot subscribing, which damages deliverability for every
later send. Sooner is safer.
