1. SINGLE PURPOSE
------------------------------------------------------------------------------
X Dim Mode restores the "Dim" dark blue theme that X (formerly Twitter) removed
from its display settings, and optionally restores other parts of X's earlier
interface. It adds Dim back as a choice inside X's own display settings, offers
six themes plus a custom colour, and includes optional toggles that bring back
the classic bird logo, the pre-Chirp font, the Twitter favicon, the word "Tweet"
instead of "Post", opening on the Following timeline, and the classic
multi-image grid. Every feature serves one purpose: making X look and read the
way it used to.
------------------------------------------------------------------------------


2. PERMISSION JUSTIFICATION — "storage"
------------------------------------------------------------------------------
Stores the user's settings so they persist between browser sessions and sync
across the user's own devices through their browser account: whether the
extension is enabled, the chosen theme, a custom colour value, and which of the
six optional Extras are switched on (classic bird logo, classic font, classic
favicon, "Tweet" wording, Start on Following, classic image grid). It also
stores a first-install timestamp and flags recording whether the user has
already dismissed or accepted the newsletter prompt, so those prompts are not
shown repeatedly. No browsing data is stored.
------------------------------------------------------------------------------


3. HOST PERMISSION JUSTIFICATION
   (for the content-script matches x.com, twitter.com, pro.x.com — this field is
   easy to overlook and submission will not go through without it)
------------------------------------------------------------------------------
The extension's only purpose is to restyle X, so it has to run on the sites
where X is served: x.com, twitter.com and pro.x.com (X Pro). On those pages it
injects CSS to recolour the interface and adds the Dim option back into X's own
display settings. It also reads page structure to locate the elements it
restyles — for example the display-settings dialog, and the timeline tabs when
the optional "Start on Following" setting is enabled. It requests no other
hosts, and no page content is collected or transmitted anywhere.
------------------------------------------------------------------------------

5. DATA USAGE
------------------------------------------------------------------------------
Tick ONLY: Personally identifiable information

Do NOT tick: health, financial, authentication, personal communications,
location, web history, user activity, website content.

Why PII: the welcome/update page and the popup contain an optional newsletter
field. If — and only if — a user types an email address and presses subscribe,
that address is sent to MailerLite. Nothing else is ever transmitted. The
privacy policy at https://xdim.app/privacy already says exactly this.
------------------------------------------------------------------------------


6. CERTIFICATIONS — tick all three
------------------------------------------------------------------------------
[x] I do not sell or transfer user data to third parties, outside of the

[x] I do not use or transfer user data for purposes that are unrelated to my

[x] I do not use or transfer user data to determine creditworthiness or for

All three are true. MailerLite is a service provider delivering a newsletter the
user explicitly opted into; the address is used only to send updates about this
